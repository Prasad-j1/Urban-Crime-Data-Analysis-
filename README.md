# 🚨 Urban Crime & Population Insights Dashboard

An interactive Power BI dashboard analyzing crime statistics, population distribution, violent crimes, property crimes, robbery, burglary, vehicle theft, and other urban crime insights across multiple cities and states.

## 📊 Key Features
- Crime trend analysis across cities
- Population group comparison
- Vehicle theft & violent crime insights
- State-wise and city-wise crime visualization
- Interactive Power BI dashboard
- KPI cards for quick analytics

## 🛠️ Tech Stack
- Power BI
- CSV Dataset
- Data Visualization
- DAX
- Data Analytics

## 📁 Dataset
Dataset used: `City Crime Dataset`

## 📈 Insights
- Property crimes are significantly higher than violent crimes
- California shows highest vehicle theft counts
- Larger population groups contribute to higher crime totals
- Larceny is the most common crime category
